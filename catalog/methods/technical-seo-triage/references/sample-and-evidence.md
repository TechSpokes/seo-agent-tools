# Define the investigation and inspect evidence

For site triage, choose a bounded representative sample from known structure, input or discovery. Record URL selection and what it misses. For indexing, identify the property, named URLs or submitted sitemap. A standalone single observation can use a direct lookup; use this method when dependent checks are needed. Inspect adequate supplied evidence first and check authority and current cost for remaining selected calls.

For each relevant URL record response status, redirects, canonical, directives and other live signals actually observed. A complete static capture can resolve a static content or link question. An extract establishes only what it contains. Use a rendered observation to test a material rendering question, and indexed-version evidence to answer what Google observed for the named URL. Sitemap submission establishes submission metadata, never a count of indexed pages.

Consult the [evidence plan](evidence-plan.json) for exact stage IDs, evidence bounds and completion criteria.

# Provenance

SEO Agent Tools was designed from public-safe behavioral analysis of the current SEO MCP compatibility surface, approved product direction, and existing content-quality contracts maintained by TechSpokes.

Private sources were used as evidence for stable behavior, decision criteria, boundaries, and migration requirements. This repository contains newly written public contracts rather than copied private implementation, fixtures, business examples, provider bindings, credentials, customer data, or deployment details.

The runtime skill preserves these durable ideas:

- The server is authoritative for current execution, availability, authorization, and cost.
- Analytical recipes are bounded, versioned decision methods rather than agent personas.
- Evidence observations are separated from interpretations and limitations.
- Content production follows diagnosis and a self-contained implementation handoff.
- Empty supported results are valid, while missing evidence produces an explicit incomplete state.
- Public methodology can scale independently of private provider and runtime machinery.

The v0.1.0 tag and repository history preserve the processed construction evidence. Active source no longer maintains an `.intake/` workspace because its durable decisions are represented in public contracts, schemas, tests, and documentation. Runtime and importer artifacts exclude source-analysis material because consumers need the transformed contracts, not the original construction context.

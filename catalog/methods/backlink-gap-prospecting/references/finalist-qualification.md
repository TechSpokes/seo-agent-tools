# Qualify the surviving prospects

For each surviving finalist, inspect its representative source page to locate the actual competitor link, surrounding context, relevance and plausible outreach angle. Record the page, linked competitor, quality concerns, provenance and any directly observed target link. A complete authorized page capture may come from a client, server or supplied source. A snippet cannot establish that relevant material is absent. A single source page says nothing conclusive about every other link from the domain.

Rank only qualified prospects within the method's bound. Report a contact route only when directly and lawfully observed. Document material rejected finalists and the reason. When all finalists lack source context, mark the result incomplete. If some are adequately observed, narrow the scoped set to those supported and state the coverage limit. Empty qualified output is legitimate after adequate screening.

# SEO Agent Tools v0.1.1

## [v0.1.1]

This patch improves repository maintenance guidance without changing the portable SEO runtime, recipe definitions, catalog contracts, or result schemas. It clarifies sandbox access for credentialed Git and GitHub operations, project-aware PhpStorm usage, self-contained writing, autonomous escalation, milestone-based work, and progressive verification.

Evaluation validation now reports exactly what the maintenance script proves: the fixture registry, required segments, and agent surface are structurally valid, while no behavioral case is considered passed unless an evaluator actually runs it and assesses its named invariants.

The new local `npm run version:check` command validates package metadata, plugin manifests, changelog identity, the current-version document, and release-note presence without using remote state. Release preflight calls the same implementation.

Local `.intake/` source-analysis material is no longer part of the tracked source tree and is ignored for future maintenance work. No release tag is created by this preparation change.

# Validate clusters and target ownership

For each finalist inspect current search results and classify the dominant intent and viable page types. Check whether an existing target page already serves the need and whether the candidate offers defensible differentiation. Inspect actual pages where snippets do not resolve overlap or role. Name incomplete evidence and limit affected requirements to provisional scope where full-page evidence is unavailable.

Return supported clusters with competitor and query evidence, differentiation, target action, effort, confidence and disposition. Separate feasibility judgments from observed rankings. Preserve a suitable existing target where change lacks evidence. Record why a plausible candidate was rejected. Complete empty when adequate evaluation finds no supported target opportunity.

Consult the [evidence plan](evidence-plan.json) for exact stage IDs, evidence bounds and completion criteria.

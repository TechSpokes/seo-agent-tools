# Recommend revisions and settle completion

For partial and unanswered rows, explain what a revision should clarify, where it belongs and what evidence or owner input it would need. Keep the observed status separate from any claim the author would need to verify. Inspect supporting material already available before escalating. A blocking decision should identify the owner or decision needed, the options, evidence and consequence. Never invent an answer to settle a private policy.

Compare the submitted list with the source wording, count and order. A schema check alone cannot compare against an external list. Use complete when all supplied questions can be assessed and each observed gap has its required recommendation. Use incomplete with the precise stop reason for a materially unresolved supplied assessment or blocking decision. Keep a concise human summary consistent with the rows. The review covers the named artifact and supplied audience questions.

# SEO Agent Tools v0.6.0

## [v0.6.0]

Use authorized connected observations or readable report exports to investigate Google organic search performance and GA4 measurement and conversion decisions. The same methods describe both routes. A supported narrow lookup can still use a direct capability.

- Organic Search Performance and Opportunity Decisions (`organic-search-performance-opportunity-decisions@1.0.0`) uses the visibility domain and returns a diagnostic with a conditional ranked opportunity set.
- GA4 Measurement and Conversion Analysis (`ga4-measurement-conversion-analysis@1.0.0`) adds the analytics domain and returns a diagnostic scoped to measurement validity, landing outcomes, ordered progression or fresh activity.
- Technical SEO Triage (`technical-seo-triage@2.1.0`) uses bounded supplied or connected indexing observations alongside relevant public page evidence.
- Page Refresh Brief (`page-refresh-brief@2.1.0`) carries supported first-party findings forward while retaining the current technical and target suitability checks for a recommended intervention.

The skill now links to [Google report export help](https://github.com/TechSpokes/seo-agent-tools/blob/main/docs/google-data-exports.md) and explains how to show the observations behind a decision, even when the evidence supports no change or only a next check.

The skill, packages and catalog advance to `0.6.0`. The catalog retains recipe schema `2` and the existing result-contract versions. It is released with the three portable archives, the catalog and manifest, and `SHA256SUMS` covering the five assets.

# SEO Agent Tools v0.2.0

## [v0.2.0]

This release makes the public recipe catalog execution-ready for immutable private-runtime import while preserving the connected server as the authority for tools, mappings, cost, authorization, and caller-specific availability.

The public contract versions are:

- portable skill and plugin packages: `0.2.0`;
- catalog: `0.2.0`;
- recipe schema: `2`;
- five seed recipes: `2.0.0` each;
- result contracts: `seo-opportunity-set/v1`, `seo-diagnostic/v1`, and `seo-implementation-handoff/v1`.

Recipe schema v2 adds source-classed and step-linked evidence plans, provider-neutral scope bounds, explicit completion-without behavior, and deterministic primary or conditional result composition. Draft 2020-12 schemas are the structural authority, with registered fixtures proving completed empty results, incomplete stopped results, evidence-reference integrity, self-contained handoffs, and expected contract failures.

The release publishes three runtime archives plus `seo-agent-tools-catalog-v0.2.0.json` and `seo-agent-tools-catalog-manifest-v0.2.0.json`. The catalog bundles canonical recipes and exact schemas. The manifest records the public source repository, tag, commit, versions, inventories, normalized source checksums, and catalog checksum without a build timestamp. `SHA256SUMS` covers all five assets, and release verification proves two byte-identical builds.

Direct analysis remains available whenever a connected compatible server exposes suitable authorized tools. Typed recipe execution additionally requires that server to support the selected public recipe version and every exact result contract in its output composition. Catalog presence is not entitlement, and agents must report version or availability skew instead of reconstructing private behavior.

This release does not claim that any private runtime has imported or deployed v0.2.0. It adds no provider, production cutover, persistent execution state, or finished content-writing behavior.

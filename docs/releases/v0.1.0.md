# SEO Agent Tools v0.1.0

## [v0.1.0]

This initial public release provides a portable skill for using a connected SEO MCP server to perform bounded, evidence-backed analysis. It covers direct evidence routing, progressive recipe discovery, content-quality diagnosis, self-contained implementation handoffs, verification, cost authorization, runtime skew, and explicit stop behavior.

The public catalog starts with five migration seed recipes and is designed to accept additional methods without embedding a fixed recipe list in the runtime skill or validator. Three versioned result families share a common evidence envelope.

Release packages contain only the canonical runtime skill and plugin wrappers. Private server implementation, raw intake, provider bindings, credentials, account state, and persistent-job machinery are excluded.

# Simplicity Review

## Method

A fresh-context agent independently reviewed the current intake and all five local repositories on 2026-07-29. It was instructed to identify over-engineering and rank the smallest architecture that preserves catalog scale, deterministic projection, runtime authorization, content-quality diagnosis, and a later persistent-run path.

No files were changed by the reviewer.

## Essential For The Initial Release

- A focused skill that teaches direct lookup versus multi-step decision, progressive server discovery, evidence discipline, diagnosis, handoff, and the content-writing stop boundary.
- One canonical file per recipe.
- A compact controlled recipe card.
- Stable capability identifiers mapped privately to current tools.
- One shared evidence envelope and a small number of result families.
- One deterministic catalog and manifest projection.
- Server-resolved availability and current cost.
- Content-quality diagnosis and an implementation handoff without drafting guidance.
- Lightweight schema, identity, projection, and representative behavioral tests.

## Deferred

- Recipe components until real duplication justifies them.
- Detailed availability reason codes until real authorization cases require them.
- Semantic compatibility machinery beyond schema-version support.
- Polished contracts that have not yet been exercised across independent recipe families.
- Persistent execution beyond stable recipe versions and step IDs.

## Removed From The Initial Public Design

- Compiled-plan models.
- Job snapshots.
- Queue, schedule, retry, checkpoint, cancellation, retention, and authorization-renewal contracts.
- Private deployment and rollback procedures.
- Mandatory prose-heavy tool plans, integrations, and fallback fields for every public recipe.
- Public duplication of current tools, prices, provider bindings, or entitlement logic.

## Accepted Design Rule

Keep a field or process only when it helps selection, safety, execution, compatibility, or verification. Put future-platform detail behind a later decision instead of making every consuming agent carry it now.

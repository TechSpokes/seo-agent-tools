# Diagnose and identify the next check

Separate current configuration from historical event reporting and from the organization's actual business outcome. A count of events does not necessarily count users, sessions or successful purchases. Preserve sampling, thresholding, consent and coverage limits where the source reports them. A missing row has no observed value. Compare observed counts only when definitions, scopes and periods support the comparison.

Link decisive values and their denominators to the source. Record an issue only when supported, with alternatives, scope, owner and a measurable follow-up. Report supported observations and an empty issue list when checks reveal no issue. Where a required field, ordered sequence or comparable period is absent, name exactly what would resolve the decision and mark the affected analysis incomplete.

Consult the [evidence plan](evidence-plan.json) for exact stage IDs, evidence bounds and completion criteria.

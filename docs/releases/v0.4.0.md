# SEO Agent Tools v0.4.0

## [v0.4.0]

This minor release adds a focused public result for reviewing the exact questions in an approved content brief against one canonical draft.

The public contract versions are:

- portable skill and plugin packages: `0.4.0`;
- catalog: `0.4.0`;
- recipe schema: `2`;
- content-production recipe: `content-production-workflow@1.1.0`;
- five existing recipes: `2.0.0` each;
- result contracts: `content-question-review/v1`, `seo-opportunity-set/v1`, `seo-diagnostic/v1`, and `seo-implementation-handoff/v1`.

`content-question-review/v1` preserves approved question wording and order, assigns one of four coverage statuses, cites readable sources directly inside each assessment, and requires scoped recommendations for partial or missing answers. Independently discovered questions remain supplemental and cannot replace or satisfy the approved brief.

The shared schema adds reusable `source` and `humanEscalation` definitions without changing the required fields or meanings of the released evidence envelope. Sources can represent web pages, tool results, files, or conversations through open kinds and locators plus text or JSON material. Stable IDs remain optional. Escalations carry a self-contained human request without assignments, workflow state, notifications, persistence, or history.

`content-production-workflow@1.1.0` emits the review conditionally when approved buyer or people-also-ask questions exist. It lets bounded keyword and question research challenge a proposed brief before approval, keeps generated query coverage supplemental afterward, and prevents publication approval while a material blocking review or escalation remains unresolved. It adds no capability, top-level input, required paid operation, persistent step, or budget default.

The release publishes three runtime archives plus `seo-agent-tools-catalog-v0.4.0.json` and `seo-agent-tools-catalog-manifest-v0.4.0.json`. The manifest records the exact immutable source commit and source checksums, and `SHA256SUMS` covers all five assets.

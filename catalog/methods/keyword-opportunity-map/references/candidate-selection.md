# Expand and trim a bounded set

Record the supplied seed, subject, intended audience and purpose. Inspect current availability, authority and pricing before paid steps. Expand no more than the declared candidate bound and group genuine variants without losing meaningful differences in intent. Distinguish proposed query language from observed demand. Collect metrics only for candidates where the result can change priority, preserving source, market, date and estimate limits.

Select a bounded set of finalists using relevance to the objective and realistic target fit. Inspect current results, including the mix of result types, for the retained queries. Record competing intent where it matters. Reject or defer candidates that depend on unavailable evidence.

# SEO Agent Tools v0.8.0

## [v0.8.0]

Each catalog method now has an entry, stage references, a worked example and the exact schemas for its deliverables. An agent can read a selected stage by its package-relative path, carry the publication identity into its next read and reuse a schema it already has from that publication. Full inspection remains available. The format 3 catalog and its manifest identify every file by UTF-8 byte length and SHA-256 digest.

Six methods now use recipe schema 3 to declare which alternative sources can supply complete page evidence at individual stages. Page Refresh, Technical SEO Triage, Backlink Gap, Competitor Opportunity Map and Keyword Opportunity Map advance to recipe version 3.0.0. Content Production Workflow advances to 2.0.0. Other recipes continue to use schema 2. A producer’s identity alone cannot establish that a capture is complete, rendered, indexed or approved.

Content Question Coverage Review assesses an ordered list of audience questions against one document or page capture. An observed gap can yield a completed review with a revision recommendation. Unreadable evidence or an unresolved decision can leave the review incomplete. See the [authoring example](../../CONTRIBUTING.md#author-a-method-package).

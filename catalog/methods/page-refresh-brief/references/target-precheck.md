# Inspect the target

Record the observed request and final URL, status, redirects, canonical, crawl directives and the provenance and time of each relevant signal. Distinguish a live directive from what a search engine has indexed. If the target is inaccessible, redirected elsewhere or explicitly marked noindex, decide whether that signal makes a comparison misleading. Return the supported bounded technical diagnosis when the evidence is sufficient. State what was never inspected. Select a technical handoff only if the intended state and fix are independently supported.

When the target is viable, carry forward its objective, existing role and known query context. Check whether any earlier performance observation has the same target, dates and scope as the pending decision. Select only the comparison evidence needed to distinguish preservation, on-page revision or a different intervention.

Consult the [evidence plan](evidence-plan.json) for exact stage IDs, evidence bounds and completion criteria.

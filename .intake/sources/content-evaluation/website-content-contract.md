# Website Content Evaluation Contract

## Source Contribution

The Business Website Content Skill contributes the broad diagnosis model for deciding whether a problem is strategic, planning-related, content-related, technical, or operational. This prevents a rewrite from becoming the default answer to every weak SEO outcome.

Confidence: `A1` for source behavior and `B2` for adaptation.

## Diagnostic Layers

### Strategic

Evaluate whether the site covers the needed business information, maps pages to distinct intents, and has a coherent relationship between broad and specific pages. Overlap, missing intent coverage, orphan pages, or incoherent architecture cannot be fixed by rewriting one paragraph.

### Planning

Evaluate whether the page has one intended user, one user job, one primary action, one onward path, a validated query, an observed intent, an appropriate page type, required proof, and a planned architecture.

### Content

Evaluate whether the page answers the intended task, makes the answer findable when scanning, uses appropriate language and depth, supports claims, handles relevant objections, and provides a clear action.

### Technical

Evaluate metadata, crawl and index signals, canonical behavior, rendering, performance, structured data, accessibility, and tracking only when the available MCP evidence can actually observe them.

### Operational

Evaluate indexing, impressions, rankings, click behavior, conversion signals, decay, and user feedback only when first-party or otherwise suitable evidence is supplied. Do not infer these facts from public SEO-tool estimates.

## Rewrite Decision

A content rewrite is justified only when evidence locates the failure in content or planning and the existing page remains the correct target for the query and page role.

A rewrite is not the default when the evidence instead indicates missing demand, wrong intent, wrong page type, technical failure, authority limitations, cannibalization, absent first-party data, or a page that already satisfies the supported criteria.

Recommend the smallest supported intervention and identify which valuable elements must be preserved.

## Handoff Fields

- Intended user, user job, primary action, and onward path.
- Primary query, close variants, intent, and situational context when relevant.
- Recommended page type and target URL.
- Evidence-backed content gaps and preserved strengths.
- Required proof and source expectations.
- Internal links justified by the reader's next step.
- Technical or operational dependencies that block content conclusions.
- Stakes level and proportional verification.
- Acceptance criteria and measurement plan.

## Excluded Material

Do not project the page creation sequence, writing guidance, rhetoric, editing passes, scan-writing techniques, conversion copy, or finished examples.

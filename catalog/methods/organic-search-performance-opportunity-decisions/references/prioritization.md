# Decide which target merits action

Filter to candidates with evidence of demand, persistence, relevance, materiality and current page suitability. Use bounded current metadata or search results when they can change target choice or rank. Investigate low CTR or overlapping URLs before recommending new content or consolidation. Preserve competing explanations. For a GA4 cross-check, align URL, property, period and acquisition scope and disclose timezone and metric differences. Query-to-conversion attribution remains unknown.

Produce the diagnostic for every selected scope, including opportunity-only inquiries. A conditional opportunity set is due only after completed prioritization finds a supported candidate. When evidence is sufficient for no action, document that disposition. When current suitability or comparability is unresolved, state the narrow discriminating check before recommending intervention.

Consult the [evidence plan](evidence-plan.json) for exact stage IDs, evidence bounds and completion criteria.

# Temporary Workspace Instructions

## Purpose

Use this directory for disposable drafts, captured command output, downloads under review, experiments, generated probes, and cross-repository coordination notes that do not belong in maintained source.

## Boundaries

- Everything in this directory except this tracked instruction file is ignored by Git.
- Never store credentials, private configuration, authoritative source, durable decisions, or the only copy of required handoff state here.
- Use a descriptive subdirectory when one task produces several related files.
- Move durable results to their owning maintained location before relying on them.
- Remove obsolete scratch material at the milestone that no longer needs it.

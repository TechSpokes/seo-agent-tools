# Work With Google Report Evidence

Use the same decision method for an authorized connected report and an adequate export the host can read. First identify the exact source, property, reporting period, search or acquisition scope, filters, dimensions, metrics, aggregation and known limits. Inspect the observations before claiming evidence. Plan readiness and a visible filename establish only prerequisites for further work.

## Choose the Source

Use already supplied evidence when it answers the question. If a direct observation is useful, discover its current operation, confirm the authorized property or stream when relevant, and check the quote for the selected inputs before a chargeable call. A plan with zero default optional calls leaves the selected connection's cost open.

For client-side analysis, give the user the [Google report export and upload guide](https://github.com/TechSpokes/seo-agent-tools/blob/main/docs/google-data-exports.md). If the host cannot read the attachment, ask for a supported format or the necessary rows and report context. If only part of the evidence is usable, answer the supported narrower question and name the smallest additional report or fields needed for the requested conclusion.

## Keep Sources Comparable

Search Console clicks, impressions, click-through rate and average position describe Google search performance. Keep property and page aggregation, returned query coverage, selection filters and independent comparison-period continuation visible. Preserve missing observations, actual zeros and ambiguous exported zeros. CTR and average position must retain their denominators or reported aggregation.

GA4 reports sessions, engagement and recorded events at defined property, acquisition and reporting scopes. A current setting establishes what is enabled at observation time. Historical event data, ordered user progression and verified business outcomes each need appropriate evidence. Use the applicable property timezone and distinguish all Organic Search from the Google organic slice. State relevant time boundaries and never assign query-level conversions from aggregates.

## Follow Up on a Decision

Route a single authorized report, setting or URL observation directly if it is sufficient. Use a recipe for dependent investigation or prioritization. Treat sitemap submission, Google's indexed-version evidence and current public page behavior as separate observations with dates and scope. Evidence from a URL sample supports conclusions about that sample.

Before routing a performance finding into a page refresh, preserve its target, decisive observations, source, reporting period, objective and uncertainty. Recheck current technical state and target suitability before deciding whether a refresh or another action is justified.

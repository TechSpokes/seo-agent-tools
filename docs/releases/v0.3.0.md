# SEO Agent Tools v0.3.0

## [v0.3.0]

This release adds the sixth public recipe, `content-production-workflow@1.0.0`, for one selected existing-site content objective. It coordinates business and editorial context, decision-relevant research before outlining, a client-owned canonical document, bounded content analysis, separate factual verification, approval, client-owned publication, live-page verification, and lifecycle ownership.

The public contract versions are:

- portable skill and plugin packages: `0.3.0`;
- catalog: `0.3.0`;
- recipe schema: `2`;
- content-production recipe: `content-production-workflow@1.0.0`;
- five existing recipes: `2.0.0` each;
- result contracts: `seo-opportunity-set/v1`, `seo-diagnostic/v1`, and `seo-implementation-handoff/v1`.

The recipe adds controlled content discovery facets, `document` and `claim-set` evidence units, and public capabilities for content context, canonical documents, bounded content analysis, factual verification, and publication evidence. It reuses `seo-implementation-handoff/v1`; the canonical page body and detailed factual-verification record remain client-owned artifacts and are not embedded in the validated result.

Content SEO analysis is the required supplied-document review. Helpfulness and readability are conditional regression checks. Keyword expansion, metrics, and current result evidence remain conditional on a decision they can change. Direct generation, rewriting, semantic relevance, query coverage, and overlap analysis do not become required recipe steps or default costs.

The recipe does not write finished copy, grant CMS authority, persist a project, schedule work, establish factual truth from content scores, or treat a staged snapshot as production proof. A capable client owns outlining, drafting, claim verification, approval, publication, page reading, artifact custody, and later lifecycle decisions. The connected server remains the authority for executable mappings, authorization, availability, current prices, freshness behavior, and caller-specific readiness.

The release includes registered activation and behavior cases for broad planning-to-publication intent, client and server responsibility boundaries, live verification after publication, and a representative completed content-production handoff. Structural validation registers those cases; behavioral pass claims still require actual fresh-context evaluation.

The release publishes three runtime archives plus `seo-agent-tools-catalog-v0.3.0.json` and `seo-agent-tools-catalog-manifest-v0.3.0.json`. The manifest records immutable source and checksum provenance, and `SHA256SUMS` covers all five assets.

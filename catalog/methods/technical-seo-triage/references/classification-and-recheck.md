# Classify findings and define rechecks

Partition supported issues, suspected issues, unaffected observed scope and unknown scope. Record the time and provenance of each finding, especially when public and indexed versions differ. Observe further evidence only for a question that can change the diagnosis. A narrower investigation can complete with adequate evidence while uninspected site scope remains unknown.

Rank up to five supported fixes or rechecks by severity and likely impact. Give the actual affected sample, confidence, intervention owner and verification. An empty diagnostic is legitimate where adequate checks found no material issue. If the selected question requires unavailable public or first-party evidence, record the affected outcome as incomplete and ask only for the smallest missing observation.

Consult the [evidence plan](evidence-plan.json) for exact stage IDs, evidence bounds and completion criteria.
